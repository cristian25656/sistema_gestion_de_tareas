Task Manager CLI
A simple Python-based Command Line Interface (CLI) to manage your daily tasks. This application allows you to create, view, update, and delete tasks efficiently.
Features

    Create Tasks: Register new tasks with ID, title, description, priority, and state.
    View All: Display a complete list of your current tasks.
    Search: Find specific tasks quickly using their unique ID.
    Update: Modify existing task details (title, description, etc.) or keep current values by leaving fields blank.
    Delete: Remove tasks from your repository with a confirmation step.
    
Usage
Run the main script and follow the on-screen menu:

    Add Task
    View Tasks
    Search Task
    Update Task
    Delete Task
    Exit
